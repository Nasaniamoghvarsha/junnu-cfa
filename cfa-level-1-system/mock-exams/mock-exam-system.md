# CFA Level I — Mock Exam System

## Purpose: Full-length exam simulations using original CFA-style questions.

---

## MOCK EXAM STRUCTURE

Each mock exam follows the official CFA Level I format:
- **180 multiple-choice questions** (A, B, C)
- **Session 1 (AM):** 90 questions, 135 minutes
- **Session 2 (PM):** 90 questions, 135 minutes
- **Average time per question:** 90 seconds
