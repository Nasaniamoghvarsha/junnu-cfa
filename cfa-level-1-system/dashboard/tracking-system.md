## 2. DASHBOARD METRICS — DEFINITIONS & TARGETS

| Metric | What It Measures | Target | How to Calculate |
|--------|-----------------|--------|-----------------|
| Curriculum Coverage | % of 222 LOs studied | 100% | Count LOs marked "Studied" / 222 |
| High-Priority Concepts | % of Tier 1 concepts with ≥3 correct answers | 96%+ | Count Tier 1 concepts with mastery / total Tier 1 |
| Question Coverage | % of concept-pattern combinations practiced | 94%+ | Practiced patterns / total patterns × concepts |
| Formula Mastery | % of 144 formulas you can recall AND apply correctly | 93%+ | Formula test accuracy |
| Ethics Readiness | % accuracy on Ethics scenarios (min 50 scenarios) | 91%+ | Ethics question bank accuracy |
| Weak Topics | Number of subtopics below 65% accuracy | 0-3 | Topics with <65% on last 10 attempts |
| Mock Average | Average % across all completed mocks | 78%+ | Sum of mock scores / mocks completed |
| Time Management | % of questions completed within target time | Strong (90%+) | Questions within time / total questions |
| Retention | Accuracy on retested concepts after 2+ weeks | 89%+ | Retest accuracy on old material |
| Active Error Patterns | Number of unresolved error patterns | 0-2 | Count patterns not marked RESOLVED |

## 2. ERROR TRACKING LOG

### 2.1 Mistake Classification

For every incorrect answer, classify:

| Category | Code | Description |
|----------|------|-------------|
| Knowledge Gap | KG | Did not know the concept |
| Formula Gap | FG | Could not recall the formula |
| Calculation Error | CE | Wrong numerical computation |
| Reading Error | RE | Misread the question |
| Conceptual Misunderstanding | CM | Understood the concept incorrectly |
| Misinterpretation | MI | Misunderstood what was being asked |
| Careless Mistake | CA | Knew it but made a silly error |
| Time-Pressure Mistake | TP | Ran out of time |
| Guess | GU | Did not know, guessed |
| Changed Answer | CH | Changed from correct to incorrect |
| Trap Failure | TF | Fell for the question's trap |

## 6. 90% PREPARATION CHECKLIST

The system will confirm "Preparation Coverage: ~90%+" when:

- [ ] All 222 Learning Outcomes covered
- [ ] 90%+ of important concepts practiced
- [ ] 90%+ of question patterns encountered
- [ ] Strong performance on all Tier 1 priority topics
- [ ] No topic with accuracy below 50%
- [ ] Formula recall accuracy ≥85%
- [ ] Ethics scenario accuracy ≥80%
- [ ] ≥3 full mock exams completed
- [ ] Mock exam scores within 10% range of each other
- [ ] All previous weak concepts retested successfully
- [ ] Average time per question ≤90 seconds
- [ ] Retention rate ≥85% on spaced retests
