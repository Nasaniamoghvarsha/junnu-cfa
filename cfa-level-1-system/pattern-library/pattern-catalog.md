# CFA Level I — Question Pattern Library

## Purpose: Catalog all recurring question structures across CFA Level I topics.

---

## PATTERN CATEGORIES

### 1. FORMULA IDENTIFICATION
**Examiner Intent:** Tests whether you can identify which formula applies to a given situation.
**Typical Wording:** "Which of the following formulas would be most appropriate..."
**Required Knowledge:** Formula names, inputs, contexts
**Typical Trap:** Similar-looking formulas; wrong formula for the context
**Difficulty:** 2-3

### 2. DIRECT CALCULATION
**Examiner Intent:** Tests ability to compute using given inputs.
**Typical Wording:** "Calculate the..."
**Required Knowledge:** Formula memorization, calculator proficiency
**Typical Trap:** Wrong inputs, unit mismatches, sign errors
**Difficulty:** 1-3

### 3. MISSING-VARIABLE PROBLEM
**Examiner Intent:** Tests ability to rearrange formulas and solve for unknown.
**Typical Wording:** "Given X and Y, the Z is closest to..."
**Required Knowledge:** Formula algebra, reverse calculation
**Typical Trap:** Incorrect algebraic manipulation
**Difficulty:** 3-4

### 4. CONCEPT COMPARISON
**Examiner Intent:** Tests understanding of relationships between concepts.
**Typical Wording:** "Compared to X, Y is..."
**Required Knowledge:** Conceptual understanding, directional relationships
**Typical Trap:** Confusing directionality; similar but distinct concepts
**Difficulty:** 2-3

### 5. SCENARIO INTERPRETATION
**Examiner Intent:** Tests ability to apply concept to a described situation.
**Typical Wording:** "Given the following scenario..." then asks for conclusion
**Required Knowledge:** Application skills, context recognition
**Typical Trap:** Irrelevant information; distractors in scenario
**Difficulty:** 2-4

### 6. FINANCIAL STATEMENT ADJUSTMENT
**Examiner Intent:** Tests ability to adjust reported figures to economic reality.
**Typical Wording:** "After adjusting for..., the [ratio/figure] would be..."
**Required Knowledge:** Accounting principles, adjustment mechanics
**Typical Trap:** Forgetting both sides of the adjustment; wrong direction
**Difficulty:** 3-4

### 7. VALUATION
**Examiner Intent:** Tests ability to determine intrinsic value.
**Typical Wording:** "The intrinsic value is closest to..."
**Required Knowledge:** DDM, DCF, multiples
**Typical Trap:** Wrong discount rate, wrong growth rate, terminal value errors
**Difficulty:** 3-4

### 8. YIELD CALCULATION
**Examiner Intent:** Tests various yield measure computations.
**Typical Wording:** "The [yield measure] is closest to..."
**Required Knowledge:** YTM, YTC, YTW, current yield, money market yields
**Typical Trap:** Confusing yield types; wrong periodicity
**Difficulty:** 2-3

### 9. RISK INTERPRETATION
**Examiner Intent:** Tests ability to identify, measure, and compare risk.
**Typical Wording:** "Which has the highest/lowest [risk measure]?"
**Required Knowledge:** Duration, beta, standard deviation, VaR
**Typical Trap:** Confusing risk types; wrong risk measure for context
**Difficulty:** 2-3

### 10. ETHICS SCENARIO
**Examiner Intent:** Tests ability to apply Standards to professional situations.
**Typical Wording:** "Does [person] most likely violate..."
**Required Knowledge:** All 22 Standards, Code of Ethics
**Typical Trap:** Overlooking subtle violations; assuming violation where there is none
**Difficulty:** 2-4

### 11. "MOST LIKELY" QUESTION
**Examiner Intent:** CFA's signature question format; tests precise knowledge.
**Typical Wording:** "...is most likely..."
**Required Knowledge:** Nuanced understanding; "best" answer among plausibles
**Typical Trap:** Multiple plausible answers; must choose MOST correct
**Difficulty:** 3-4

### 12. "LEAST LIKELY" QUESTION
**Examiner Intent:** Reverse reasoning; tests comprehensive knowledge.
**Typical Wording:** "...is least likely..."
**Required Knowledge:** Knowledge of what is NOT true/appropriate
**Typical Trap:** Forgetting the "least" framing; choosing a true statement
**Difficulty:** 3-4

### 13. IMPACT OF CHANGING ONE VARIABLE
**Examiner Intent:** Tests sensitivity analysis and directional understanding.
**Typical Wording:** "If X increases, [result] will most likely..."
**Required Knowledge:** Variable relationships, directional logic
**Typical Trap:** Direction confusion; non-linear relationships
**Difficulty:** 2-3

### 14. MULTI-STEP CALCULATION
**Examiner Intent:** Tests ability to chain multiple calculations.
**Typical Wording:** Implicit — requires intermediate calculations
**Required Knowledge:** Sequential computation, intermediate results
**Typical Trap:** Rounding errors; skipping steps; wrong intermediate result
**Difficulty:** 3-5

### 15. CONCEPT + CALCULATION COMBINATION
**Examiner Intent:** Tests both conceptual knowledge and calculation skill.
**Typical Wording:** "Calculate X AND interpret the result..."
**Required Knowledge:** Both formula and conceptual framework
**Typical Trap:** Correct calculation, wrong interpretation (or vice versa)
**Difficulty:** 3-4

## PATTERN-BY-SUBJECT MAPPING

### Quantitative Methods — Dominant Patterns
- Direct Calculation (TVM, statistics, regression)
- Formula Identification (which test statistic to use)
- Concept Comparison (distribution types, error types)
- Missing-Variable (solve for r, n, or PMT)
- Multi-Step Calculation (portfolio math)

### Economics — Dominant Patterns
- Concept Comparison (market structures, policies)
- Impact of Changing One Variable (elasticity, policy effects)
- Scenario Interpretation (business cycle, policy response)
- Direct Calculation (GDP, exchange rates, elasticity)

### Financial Statement Analysis — Dominant Patterns
- Direct Calculation (ratios, EPS, CFO, FCF)
- Financial Statement Adjustment (inventory, depreciation, taxes)
- Concept Comparison (IFRS vs. GAAP, methods)
- Multi-Step Calculation (DuPont, cash flow construction)
- "Most Likely" (quality assessment)

### Corporate Issuers — Dominant Patterns
- Direct Calculation (NPV, IRR, WACC, leverage)
- Concept Comparison (capital structure theories)
- Missing-Variable (cost of capital components)
- Impact of Changing One Variable (leverage, working capital)

### Equity Investments — Dominant Patterns
- Valuation (DDM, multiples)
- Direct Calculation (index values, margin, ratios)
- Concept Comparison (market efficiency forms)
- Multi-Step Calculation (multi-stage DDM, EV)

### Fixed Income — Dominant Patterns
- Direct Calculation (price, duration, convexity)
- Yield Calculation (YTM, YTC, YTW, spreads)
- Concept Comparison (duration types, yield measures)
- Multi-Step Calculation (price change with convexity)
- Impact of Changing One Variable (rates, spreads)

### Derivatives — Dominant Patterns
- Direct Calculation (forward price, option value)
- Formula Identification (which parity relationship)
- Concept Comparison (forward vs. futures, call vs. put)
- Missing-Variable (solve for missing parity component)

### Alternative Investments — Dominant Patterns
- Direct Calculation (fees, MOIC, returns)
- Concept Comparison (strategies, structures)
- Scenario Interpretation (fee structures, performance)

### Portfolio Management — Dominant Patterns
- Direct Calculation (portfolio return, risk, performance measures)
- Concept Comparison (CAL vs. CML, Sharpe vs. Treynor)
- Scenario Interpretation (IPS, behavioral biases)
- Multi-Step Calculation (optimal portfolio weights)

### Ethics — Dominant Patterns
- Ethics Scenario (violation/no violation)
- "Most Appropriate Action"
- "Least Likely Violation"
- Concept Comparison (similar but distinct standards)
